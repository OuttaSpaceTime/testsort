# Implementation Plan: Line-Level Coverage with Diff-Offset Adjustment

**Planning Mode:** A (Scout-Backed)  
**Scout:** `.claude/docs/scouts/002-line-level-coverage-with-offset-adjustment-20260413.md`  
**Date:** 2026-04-13

## TL;DR

Add line-level coverage tracking as a second layer on top of the existing file-level matrix. Per-example matrix rows enable `rspec spec:line` output. A uniform diff-offset adjuster keeps stale coverage usable across edits. File-level fallback for pure insertions and deletions. Integration tests cover dirty→tracked→dirty→tracked cycles.

## Source Requirements

- Scout decisions: two-layer storage, per-example rows, uniform offset adjustment, file-level fallback for pure insertions, JSON line vectors, no mid-run re-ranking
- User requirement: integration tests against a real temp repo in `spec/`, covering multi-cycle dirty→tracked scenarios
- Strategies (`absolute.rb`, `additional.rb`, `additional_pseudo.rb`) remain unchanged

## Objective

Enable testsort to prioritize test examples at line-level granularity while preserving file-level as a fast filter and fallback, with coverage data that remains usable across multiple dirty/committed edits.

## Before / After and Execution Flow

### Current flow (file-level):
1. `spec_helper_coverage.rb` → `CoverageMeasurement#cover(example)` → `process_coverage_result` sums line hits per file → stores one number in `matrix[spec_file, source_file]`
2. `testsort prioritized` → `Changeset#affected` returns file paths → `Prioritization#affected_file_indices` maps to column indices → strategy slices matrix → outputs `rspec spec/file1.rb spec/file2.rb`

### New flow (line-level):
1. `spec_helper_coverage.rb` → `CoverageMeasurement#cover(example)` → `process_coverage_result` sums line hits per file AND records individual line numbers in `LineVectorStore` → stores `matrix["spec:42", source_file]` + `line_vectors[("spec:42", source_file)] = [10, 11, 15, 22]`
2. `testsort prioritized` →
   - `Changeset#affected` returns file paths + `Changeset#diff_hunks` returns hunks per file
   - `DiffOffsetAdjuster` adjusts stored spec keys (old → new line numbers) and stored source line vectors
   - For modified files: `Prioritization` does file-level filter, then intersects adjusted line vectors with changed source lines → reduced example set
   - For pure insertions/deleted files: file-level fallback
   - Identifies new/modified `it` blocks from spec-side diff hunks
   - Priority ordering: new/modified examples → line-matched → file-matched → rest
   - Outputs `rspec spec/user_spec.rb:90:45 spec/order_spec.rb:30`

### Delta points:
- `file_path(spec)` returns `"path:line"` instead of `"path"` (per-example rows)
- `process_coverage_result` additionally populates `LineVectorStore`
- `Changeset` gains `diff_hunks` method
- New `DiffOffsetAdjuster` bridges stale → current line numbers
- `Prioritization#affected_file_indices` wrapped by new `affected_example_indices` that adds line-level filtering
- Command output uses `spec:line` format

### Loop closure:
- **Trigger:** developer edits files, runs `testsort prioritized`
- **State change:** stale coverage offset-adjusted, examples prioritized by line relevance, fresh coverage collected for executed examples
- **Completion signal:** correct examples run first; fresh coverage stored for next invocation
- **Multi-cycle:** dirty→tracked→dirty→tracked works because offset adjustment uses current diff hunks against HEAD, not stored state

module Testsort
  class CoverageMeasurement
    class LineVectorStore
      attr_reader :vectors

      def initialize(vectors = {})
        @vectors = vectors
      end

      def store(example_idx, file_idx, line_numbers)
        key = "#{example_idx},#{file_idx}"
        @vectors[key] = line_numbers
      end

      def lookup(example_idx, file_idx)
        @vectors["#{example_idx},#{file_idx}"]
      end

      def merge!(other_store)
        @vectors.merge!(other_store.vectors)
      end

      def to_json_data
        @vectors.transform_values { |lines| lines.sort }
      end

      def self.from_json_data(data)
        new(data || {})
      end
    end
  end
end

# frozen_string_literal: true

module Testsort
  class DiffOffsetAdjuster
    # Adjusts old line numbers forward through diff hunks.
    # Returns array of adjusted line numbers.
    def self.adjust_lines(old_lines, hunks)
      return old_lines if hunks.blank?

      sorted_hunks = hunks.sort_by(&:old_start)
      old_lines.map { |line| adjust_single_line(line, sorted_hunks) }.compact
    end

    # Adjusts a spec key "path:old_line" to "path:new_line".
    def self.adjust_spec_key(old_key, hunks)
      path, _, line_str = old_key.rpartition(':')
      return old_key if path.empty?

      old_line = line_str.to_i
      new_line = adjust_single_line(old_line, hunks.sort_by(&:old_start))
      return nil unless new_line

      "#{path}:#{new_line}"
    end

    # Returns old line numbers that were modified (replaced/deleted in a hunk).
    def self.changed_old_lines(hunks)
      lines = []
      hunks.each do |hunk|
        hunk.each_line do |line|
          lines << line.old_lineno if line.line_origin == :deletion
        end
      end
      lines
    end

    # True if hunks contain only additions (no deletions or modifications).
    def self.pure_insertion?(hunks)
      hunks.all? do |hunk|
        hunk.each_line.none?(&:deletion?)
      end
    end

    def self.adjust_single_line(old_line, sorted_hunks)
      cumulative_offset = 0

      sorted_hunks.each do |hunk|
        hunk_old_end = hunk.old_start + hunk.old_lines - 1

        if old_line < hunk.old_start
          return old_line + cumulative_offset
        elsif old_line <= hunk_old_end
          # Line is inside this hunk — check if it's a context line or modified
          return nil if line_was_deleted?(old_line, hunk)
          return old_line + cumulative_offset + (hunk.new_lines - hunk.old_lines)
        end

        cumulative_offset += (hunk.new_lines - hunk.old_lines)
      end

      old_line + cumulative_offset
    end
    private_class_method :adjust_single_line

    def self.line_was_deleted?(old_line, hunk)
      hunk.each_line do |line|
        return true if line.old_lineno == old_line && line.line_origin == :deletion
      end
      false
    end
    private_class_method :line_was_deleted?
  end
end
